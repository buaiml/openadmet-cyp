Whippoorwill OpenADMET CYP competition direct inhibition track report

This OpenADMET competition submission was made by Inductive.

Use of challenge data

We attempted to make maximal use of provided competition data, and to match our models’ training distribution to the test distribution. Our treatment varied based on isoform.

One of our first observations was that isoforms differed in how much bias there was in how single-concentration screened compounds were selected for DRC (pIC50) measurement. For 2C9 and 3A4 there was relatively little bias, so the measured training pIC50s represent the full range of observable pIC50s. However, for 1A2 and 2D6, there is considerable bias. For both isoforms, compounds with high log2 fold change (i.e., little inhibition) in the single concentration screen were much less likely to be selected for DRC, causing the measured set of pIC50s to be skewed high. This led us to train primarily on what we called our “combined” label set for these two isoforms, as described below.

To generate the “combined” label set, we created isotonic regression lines to estimate what pIC50 was typical for a given log2fc measurement, and used this to impute pIC50s for compounds with only log2fc measurements. For 1A2 this is fairly straightforward because there are a reasonable number of compounds with high log2fc values. Coverage becomes sparse around 0, so we set an “anchor” at 0 and imputed a pIC50 of 2 for any 1A2 compound with a log2fc above 0. For 2D6, imputation is more difficult because there are 0 compounds with log2fc > -0.59 that were measured for DRC. Given the shape of the log2fc to pIC50 curve seen for other isoforms, we simply imputed a curve that steadily dropped to a value of 2.0 at 0.4 log2fc, the modal value for high-log2fc compounds.

In total, the competition training data used for our primary pIC50 training was:

  •  4,375 1A2 (combined measured + log2fc-imputed)
  • 4,375 2D6 (combined measured + log2fc-imputed)
  • 2,335 3A4 (measured only)
  • 1,285 2C9 (measured only)

In addition, log2fc measurements and TDI-condition measurements were used directly as auxiliary tasks during training.

Evaluation splitting

The 750-compound test set is composed of close analogs of 75 training compounds, so train-test similarity is high. This makes traditional splitting approaches among the diverse training set such as scaffold splitting less representative of test performance. We algorithmically created a “blindlike” split that sought to identify a set of holdout compounds from the training set that approximates the similarity-to-train distribution seen in the real blind test set. While this was impossible to do perfectly given the diversity of the training compounds, the resulting blindlike test set did more closely match the nearest-training-neighbor distribution seen in the test set, and tended to be a better guide for model development than scaffold splitting.

Additional data

In addition to challenge data, during model training we used both public and proprietary data from several sources. We used public CYP data from sources including ChEMBL, Tox21, and PubChem AID 1851. We additionally used proprietary CYP data, both public and proprietary LogD data, and both public and proprietary pKa data.

Modeling approaches

Submissions were based on several complementary modeling approaches including:

  • 2D graph neural networks using the featurized ligand molecular graph.
  • 3D graph neural networks using low-energy conformers of the ligand (no information about CYP protein structure was used in our modeling approach)
  • TabM networks using pretrained GNN embeddings as inputs.

Models were generally trained with the competition pIC50 and Log2fc data as training tasks in a multi-task manner, with non-competition CYP data and non-CYP data (LogD and pKa) as auxiliary tasks. Hyperparameters and task weighting were optimized using the blindlike split. Models that appeared high-performing were submitted to the live leaderboard to assess their performance, and final submission was based on a non-negative optimized mix of individual model components.

Optimization for ST-RAE scoring metric

The competition ranks participants based on their ST-RAE, where predictions are only penalized for falling outside of the credible interval for the measured value. Because CI’s are systematically wider for low-pIC50 compounds, there is a strong incentive to shift predictions up for low-pIC50 predictions in order to minimize expected ST-RAE. To accomplish this, we ran a simulation for each prediction, assuming Gaussian error, to identify what the ST-RAE-minimizing point would be for predictions of a given pIC50.
