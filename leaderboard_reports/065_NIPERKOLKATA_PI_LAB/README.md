# OpenADMET Challenge: Predicting CYP Inhibition

A research codebase for computational modelling tasks undertaken as part of the OpenADMET Challenge, with separate project areas for **CYP2D6** and **CYP3A4**.

The repository is organized by CYP isoform so that each workflow can be developed, documented, and reproduced independently.

## Project areas

### [Predicting CYP2D6](./Predicting_CYP2D6/)

Code and documentation for CYP2D6 prediction tasks, including:

- Regression
- Time-dependent inhibition (TDI) classification

### [Predicting CYP3A4](./Predicting_CYP3A4/)

Code and documentation for CYP3A4 prediction tasks, including:

- Regression
- Time-dependent inhibition (TDI) classification
- Protein–ligand structure prediction

> The folders above are the planned repository structure. Add each workflow's code and its own README as it is prepared for release.
