    "# OpenADMET CYP Challenge method report\n",
    "\n",
    "Two prediction files are produced by the code below.\n",
    "\n",
    "| File | Track | Contents |\n",
    "|---|---|---|\n",
    "| `activity_submission.csv` | Regression Prediction | 750 rows: `SMILES`, `Molecule_Name`, four `pIC50_direct_inhibition` columns |\n",
    "| `tdi_submission.csv` | Classification Prediction | 750 rows: `SMILES`, `Molecule_Name`, `CYP3A4_is_TDI`, `CYP2D6_is_TDI` |\n",
    "\n",
    "Both tracks use one representation: Morgan fingerprints, radius 2, 2048 bits, plus eight RDKit descriptors. The descriptors are molecular weight, MolLogP, TPSA, hydrogen-bond donors, hydrogen-bond acceptors, rotatable bonds, aromatic rings, and FractionCSP3.\n",
    "\n",
    "Direct Inhibition is a separate LightGBM regressor for each isoform. Time-dependent inhibition is a separate LightGBM classifier for CYP3A4 and CYP2D6. The Boolean cutoff is chosen inside the training fold. The submitted models are refit on every labeled training row. Predictions are not shrunk toward the training mean.\n",
    "\n",
    "The scores printed in this notebook are training-set estimates from one declared split. They are not the leaderboard score. The blinded test file supplies `SMILES` and `Molecule_Name` only.\n"
   ]

    "## Declared choices\n",
    "\n",
    "- Missing `pIC50` or `is_TDI` values are dropped for that endpoint. A missing label is not used as a negative, and it is not imputed.\n",
    "- Another isoform's experimental `pIC50`, confidence interval, or standard deviation is not a feature.\n",
    "- Direct Inhibition validation is one Murcko-scaffold `GroupShuffleSplit`, `test_size=0.2`, `random_state=42`. In the code, `test_idx` is this validation fold.\n",
    "- TDI validation is one stratified `train_test_split`, `test_size=0.2`, `random_state=42`. The cutoff is chosen on an inner 20% of that training fold, over the grid 0.05, 0.10, ..., 0.95. The outer 20% is scored once.\n",
    "- LightGBM settings are fixed: 200 trees, learning rate 0.05, 31 leaves, row subsample 0.8 at every tree, column subsample 0.8, `random_state=42`. Classifiers set `scale_pos_weight` to the negative-to-positive count of the rows in that fit.\n",
    "- `verbosity=-1` only hides the training log.\n"
   ]

    "import numpy as np\n",
    "import pandas as pd\n",
    "from rdkit import Chem\n",
    "from rdkit.Chem import Descriptors\n",
    "from rdkit.Chem import rdFingerprintGenerator\n",
    "from rdkit.Chem.Scaffolds import MurckoScaffold\n",
    "from lightgbm import LGBMRegressor, LGBMClassifier\n",
    "from sklearn.metrics import matthews_corrcoef\n",
    "from sklearn.model_selection import GroupShuffleSplit, train_test_split\n",
    "\n",
    "def get_scaffold(smiles):\n",
    "    # Murcko scaffold string used as the group id for the activity split.\n",
    "    mol = Chem.MolFromSmiles(smiles)\n",
    "    if mol is None:\n",
    "        return None\n",
    "    return Chem.MolToSmiles(MurckoScaffold.GetScaffoldForMol(mol))\n",
    "\n",
    "morgan_gen = rdFingerprintGenerator.GetMorganGenerator(radius=2, fpSize=2048)\n",
    "\n",
    "def morgan_bits(smiles):\n",
    "    # 2048 bits. Radius 2.\n",
    "    mol = Chem.MolFromSmiles(smiles)\n",
    "    if mol is None:\n",
    "        return None\n",
    "    return np.asarray(morgan_gen.GetFingerprint(mol), dtype=np.float64)\n",
    "\n",
    "def descriptor_row(smiles):\n",
    "    # Eight descriptors, in this order, appended after the fingerprint.\n",
    "    mol = Chem.MolFromSmiles(smiles)\n",
    "    if mol is None:\n",
    "        return None\n",
    "    return [\n",
    "        Descriptors.MolWt(mol),\n",
    "        Descriptors.MolLogP(mol),\n",
    "        Descriptors.TPSA(mol),\n",
    "        Descriptors.NumHDonors(mol),\n",
    "        Descriptors.NumHAcceptors(mol),\n",
    "        Descriptors.NumRotatableBonds(mol),\n",
    "        Descriptors.NumAromaticRings(mol),\n",
    "        Descriptors.FractionCSP3(mol),\n",
    "    ]\n",
    "\n",
    "def strae_calc(experimental, predicted, conf_low, conf_high):\n",
    "    # Soft error is zero inside [conf_low, conf_high], otherwise the distance to the nearest bound.\n",
    "    # The denominator is that same soft error for a constant equal to the mean of experimental.\n",
    "    above = np.clip(predicted - conf_high, a_min=0, a_max=None)\n",
    "    below = np.clip(conf_low - predicted, a_min=0, a_max=None)\n",
    "    model_soft_error = above + below\n",
    "    baseline = np.mean(experimental)\n",
    "    baseline_above = np.clip(baseline - conf_high, a_min=0, a_max=None)\n",
    "    baseline_below = np.clip(conf_low - baseline, a_min=0, a_max=None)\n",
    "    baseline_soft_error = baseline_above + baseline_below\n",
    "    return np.sum(model_soft_error) / np.sum(baseline_soft_error)\n",
    "\n",
    "def feature_matrix(smiles):\n",
    "    # Shared by Direct Inhibition and TDI: 2048 bits plus 8 descriptors.\n",
    "    morgan = np.vstack(smiles.apply(morgan_bits).to_numpy())\n",
    "    descriptors = np.array(smiles.apply(descriptor_row).tolist())\n",
    "    return np.hstack([morgan, descriptors])\n",
    "\n",
    "def make_regressor():\n",
    "    return LGBMRegressor(\n",
    "        n_estimators=200,\n",
    "        learning_rate=0.05,\n",
    "        num_leaves=31,\n",
    "        subsample=0.8,\n",
    "        subsample_freq=1,\n",
    "        colsample_bytree=0.8,\n",
    "        random_state=42,\n",
    "        verbosity=-1,\n",
    "    )\n",
    "\n",
    "def make_classifier(y_rows):\n",
    "    # The weight uses only the rows about to be fit.\n",
    "    return LGBMClassifier(\n",
    "        n_estimators=200,\n",
    "        learning_rate=0.05,\n",
    "        num_leaves=31,\n",
    "        subsample=0.8,\n",
    "        subsample_freq=1,\n",
    "        colsample_bytree=0.8,\n",
    "        scale_pos_weight=(y_rows == 0).sum() / (y_rows == 1).sum(),\n",
    "        random_state=42,\n",
    "        verbosity=-1,\n",
    "    )\n"
   ]
