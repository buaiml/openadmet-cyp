## Current disclosure and evidence limitations

The model uses released direct-inhibition training labels and existing molecular-feature caches. No extra bioactivity labels or hidden challenge labels were added to the V3 recipe. Features include cached commercial-toolkit Gasteiger summaries and tree fingerprints; the use of such features does not imply that source code, cached feature files or software licenses are publicly redistributable. This private report grants no rights or code-release consent.

The released potency bounds are Bayesian curve-fit credible summaries. The model's smooth band penalty is an operational training objective; it is not a validated censored-observation likelihood or a calibrated measurement-noise model. Its interior gradient is generally nonzero, unlike the official scoring metric's zero penalty inside the bounds.

Internal scores below evaluate adaptive nested selection policies on repeatedly inspected training data. They are not blind challenge scores, nor independent fixed-configuration validation of every final full-data-selected model. Source hashes and earlier language-model reviews support provenance and reviewability, not experimental validation or professional certification.

The newly assembled adversarial review bundle provides core code, original preregistration, saved transfer/stress/ablation arrays, several selection artifacts and current hashes. Ten selected files were unreadable within bounded attempts, including the combined nested-validation archive and some final-selection/model artifacts. This limits independent reproduction from that bundle; it does not show that the original scientific outputs were wrong or that missing files are lost. No scientific refit was used to recreate missing evidence.
