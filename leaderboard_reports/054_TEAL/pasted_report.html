Overview

We predicted pIC50 for direct inhibition of four cytochrome P450 isoforms (CYP1A2, CYP2C9, CYP2D6 and CYP3A4) with a consensus of three complementary modelling pipelines. Each pipeline captures different information: learned graph representations, transfer from the log2fC readout, and feature-selected classical descriptors fed to a tabular foundation model. The final prediction is the ensemble of all three.

Model 1: Chemprop with log2fC tasks

We trained a Chemprop directed message-passing neural network (D-MPNN) in a multitask setup, using log2FC values as the learning tasks. Training on this related, richer readout lets the network learn representations of CYP-relevant chemistry that carry over to the inhibition endpoints.

Model 2: log2fC models as features

Separate log2fC models were built and their predictions were used as input features for downstream models. This is a stacking-style transfer approach: the log2FC predictions give each compound a compact, assay-informed summary of its likely CYP activity.

Model 3: Feature-selected TabPFN

We computed three feature families for each compound:

  • MolFormer embeddings (learned, transformer-based representations)
  • ECFP4 fingerprints (circular substructure features)
  • Mordred descriptors (physicochemical and topological properties)

For each isoform, we trained an ensemble of Random Forest, XGBoost and LightGBM on these features. Each model produced a feature-importance ranking. We took the top 500 features from each ranking and kept only the features common to all three lists, so the retained features are important regardless of the learning algorithm. This reduced the dimensionality and removed noise and model-specific artefacts. We then trained TabPFN models on the selected features, since TabPFN works best on small to medium tabular datasets with compact feature sets.

Final ensemble

The final prediction for each isoform is the ensemble (average) of the three components:

  1. Chemprop (log2fC multitask)
  2. Models using log2fC-derived features
  3. TabPFN on consensus-selected features
