CYP inhibition prediction with CPU models

This entry predicts direct-inhibition pIC50 for CYP1A2, CYP2C9, CYP2D6 and CYP3A4 in the OpenADMET CYP challenge. We blend LightGBM predictions (75%) with TabICLv2 predictions (25%). We have not measured a blinded-test score and make no rank claim.

We use the organizer's primary inhibition training table at dataset revision d7eb3c973dca01aad8e33c91c29e5123fd925d8f: data and provenance. It contains 4,905 compounds, with missing labels masked separately per assay. No proprietary data, released test labels, auxiliary assay labels or previous leaderboard feedback enter this recipe. TabICLv2 is a public pretrained model; its pretraining corpus was not audited for molecular-domain overlap.

Validation

Before model fitting, we standardized molecular fragments and charges with RDKit, grouped compounds by the first InChIKey block, ordered groups by their largest numeric compound ID, and held out the last 20% of groups. IDs have no documented date mapping: this is an ID-order proxy, not confirmed temporal validation. The cut point was not tuned. No connectivity group crosses the split; no blinded compound shares standardized connectivity with a training compound.

Selection uses the organizer's macro soft-threshold RAE: predictions inside an experimental credible interval incur zero error; both model error and the validation-mean reference error use distance to that interval. We checked our implementation against the organizer's evaluation code.

The training-mean reference scores 1.0351. A molecule bootstrap (2,000 draws, seed 20261104) gives a 95% interval of 0.7074–0.8275 for the selected blend. This interval is conditional on this split and selection; it excludes uncertainty from choosing among candidate recipes. It is not a test-score guarantee.

Models

RDKit 2026.09.1 supplies 32 physicochemical descriptors. LightGBM additionally uses 2,048-bit chiral Morgan fingerprints with radius 2. Median imputation is fitted only on observed-target training rows, independently for each endpoint. Targets remain on the supplied pIC50 scale; predictions receive no calibration or outcome-based clipping.

LightGBM 4.7 uses L1 loss, 600 trees, 31 leaves, learning rate 0.03, minimum child size 20, L2 penalty 5, feature fraction 0.8 and row fraction 0.8 sampled every iteration. Seed 17 and deterministic row-wise training are fixed. TabICL 2.2 uses one estimator on the 32 descriptors, seed 17, with the public TabICL regressor checkpoint tabicl-regressor-v2-20260212.ckpt, revision 4dcd344ece2c00be9e831fdd35bed57b5ad83e19.

The fixed candidate budget compared L1/L2 LightGBM, this TabICL, and Tanimoto kernel ridge with penalties 0.01, 0.1, 1 and 10. It also compared equal pairs, an equal four-model blend using the best kernel penalty, and quarter-weight variants of the best equal pair. One global blend weight applies to all four assays. All choices used the training-only validation. The selected recipe was then fitted on every observed training label and produced four predictions for each of the 750 blinded compounds. Training and inference used CPUs only.
