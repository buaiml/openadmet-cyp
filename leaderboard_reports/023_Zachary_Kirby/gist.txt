# Regression method report

## Submission scope

No non-public proprietary data were used. Public pretrained models were used: frozen CheMeleon,
ADMET-AI and MoLFormer (CYP2D6 column only) as feature sources, and CheMeleon weights as the
starting point for a fine-tuned Chemprop member. See "Pretrained components and
training-set overlap" below.

## Data

The models use the challenge-provided direct-inhibition pIC50 labels. The label matrix is sparse:
a compound may be measured against some isoforms and not others. Missing labels are masked per
endpoint rather than dropped, so a compound contributes to every endpoint for which it has a
measurement and to none where it does not.

For CYP2D6 only, a separate single-concentration activity screen is used to derive a ranking
feature (see below). That screen is used as a ranking signal, not as a pIC50 label.

## Molecular representation

The shared representation is a concatenation of:

1. A 1,024-bit radius-2 Morgan count fingerprint.
2. A 1,024-bit atom-pair count fingerprint.
3. RDKit molecular descriptors.

Two learned representations are used in addition, per endpoint:

- A 2,048-value embedding from a frozen CheMeleon D-MPNN encoder, itself pretrained to predict
  Mordred descriptors. It is worse than the descriptor matrix alone on every endpoint and helps in
  a blend on three of four. It is excluded from CYP2C9, where it hurt.
- A multitask Chemprop D-MPNN initialised from CheMeleon and then fine-tuned on the challenge
  labels (so, unlike the embedding above, not frozen). It is the weakest single model on
  three of four endpoints and improves all four in a blend.

## Base models

The common configuration is a wide-shallow gradient-boosted tree: 1,200 iterations of 15-leaf
trees at learning rate 0.03. At this number of labelled rows the binding constraint is variance
rather than capacity, so many shallow trees were preferred to few deep ones.

Per endpoint, the blend adds:

- **CYP1A2** — L1 loss, stacking, CheMeleon and Chemprop members.
- **CYP2C9** — stacking and Chemprop, plus a feed-forward network member (two 1,024-unit layers,
  dropout 0.2) that replaced an earlier union member.
- **CYP2D6** — stacking, a ChEMBL-pooled member, CheMeleon and Chemprop.
- **CYP3A4** — inverse-confidence-interval weighting and Chemprop.

"Stacking" means an endpoint is refit with the other three isoforms' predictions appended as
features. Training rows receive those columns from an inner cross-validation fold.

## CYP2D6 ranking member

CYP2D6 was the weakest endpoint. Its column added a ranking member derived from the
single-concentration activity screen: the standardised base prediction and the standardised rank
of the screen-derived activity probability are mixed at weight 0.4 on the screen term, then
re-placed onto the base column's location and scale. This is a pure ranking change: the column's mean and standard deviation are preserved.

## Teacher-feature member

One further member is added to all four endpoints. An L1-loss histogram gradient-boosted tree is
fit on the shared feature stack concatenated with 52 predictions from ADMET-AI 2.0.1, a public
pretrained ADMET predictor applied per molecule. Its output is mixed into each endpoint's column at
weight 0.20, with placement held exactly by z-matching so each column retains the base bank's mean
and standard deviation.

## MoLFormer member (CYP2D6 column only)

The CYP2D6 column additionally mixes in, at weight 0.10, a histogram gradient-boosted tree fit
on the shared feature stack together with the ADMET-AI teacher predictions and a 768-value
embedding from a frozen public MoLFormer model (pinned revision
`361063d0ad524ef77cf39b08469f6be770dc550f`). Placement is again held by z-matching.

## Final per-endpoint composition

| endpoint | column taken from | members |
|---|---|---|
| CYP1A2 | `exp140counts` | base blend (an earlier fingerprint variant), no teacher member |
| CYP2C9 | `teachmix20` | base blend + teacher member at 0.20 |
| CYP2D6 | `exp331molformer` | base blend + ranking member + teacher at 0.20, then MoLFormer member at 0.10 |
| CYP3A4 | `exp152act` | base blend, no teacher member |

## Pretrained components and training-set overlap

The ADMET-AI CYP tasks derive from the public Veith / PubChem AID 1851 dataset. An audit found 151
of 4,905 challenge training molecules (3.1%) present in that source.

## Model selection

Model selection used an analogue cross-validation split that holds out hit-expansion analogues of
potent anchors, mirroring how the blinded set was constructed. A scaffold split was used as a
secondary far-transfer check. Candidate members were screened on these splits.

The teacher member was measured on analogue folds at the same mixing weight against both the
reconstructed base bank and a matched existing-GBT control, improving macro ST-RAE on 5/5 folds for
CYP1A2, CYP2C9 and CYP3A4 and 4/5 for CYP2D6, with Spearman correlation rising on all four
endpoints. The direction was confirmed on the scaffold split.

The teacher member's mixing weight of 0.20 was chosen over 0.40 on the public live subset:
the two otherwise-identical submissions scored macro ST-RAE 0.4361 and 0.4502.

## AI Disclosure

AI was used in the design of this model. Most work was done with Opus with a custom support harness. The harness consisted of a few features:

1. A "handoff" message board that allowed Opus to delegate tasks and experiments to sub agents, request reviews from other models (e.g., Astra), and otherwise coordinate work.
2. A "workstation" which was roughly a markdown repository and a set of custom scripts. The repo contained documentation on experiments that were run (collectively almost 400 individual experiments) as well as notes and documentation on previous submissions. The scripts included support for vast.ai instance monitoring and usage as well as submission and model training utilities.
3. Review "hooks" which fired off other agents depending on a particular lifecycle action. For instance, before the next submission or when a submission was coming up. One of the primary jobs of the review agent was creating videos, documentation, and explainers for the agents work. This allowed for humans to provide guidance and input as the system operated autonomously.

While AI was used to drive much of the model design, this submission still represents hundreds of hours of human work from review and direction setting.
